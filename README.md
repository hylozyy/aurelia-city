**Neon Atlantic — Azure Cove**: an original sun-soaked open-world crime game built for make.fun's "Make GTA 6" bounty. Explore the coastal city of Azure Cove on foot and by car, steal any parked car, drift through sunny boulevards, build a wanted level, flee or fight the Cove PD, and run a three-mission story with its own cash-boost activity. All names, characters, art, audio and code are original.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or serve the static game directly:

```sh
python3 -m http.server 8080 --directory game
```
